Analyze Structures previews a single PDB/mmCIF locally. Selecting Analyze sends
coordinates and optional confidence metadata to the configured Python service.
One structure produces descriptors and warnings. Comparable pools also produce
MM-align distances, HDBSCAN clustering, medoids, shortlist eligibility, and a
complete downloadable archive. No predictions are generated. Missing confidence
is not inferred. See services/amyloid/README.txt for science, limits, and hosting.

Set AMYLOID_API_URL to the worker's public HTTPS base URL (or localhost HTTP for
development). The frontend uploads directly to that endpoint. If no worker is
configured, analysis is visibly unavailable; preview and report reading remain.
The service is not deployed automatically by a website build or PR merge.

Open Existing Reports reads files entirely in the browser: one gate-report 1.0
JSON, optionally one structural-pipeline-manifest 1.1 JSON and original PDB/mmCIF.
The reader compares SHA-256 over raw bytes: gate -> manifest -> coordinates.
This establishes file pairing, not scientific correctness. A lone coordinate
file opens as an unscored preview. Changing manifest whitespace changes its hash.
The renderer supports model index 0 and never silently substitutes another model.
Warnings are assembly-level; this version does not map them onto residues.

Package invocation in its installed environment:
amyloid-structural-pipeline --structure candidate.pdb --prediction-id candidate --output-directory results
amyloid-gates --manifest results/candidate/candidate.manifest.json --output results/candidate/candidate.gates.json

Regenerate public examples from the pinned package:
python examples/pilot5/run.py --target 2BEG --target 6QJH --output-directory /tmp/amyloid-examples
Then from the website:
python scripts/export-amyloid-examples.py /path/to/package /tmp/amyloid-examples

Examples are predicted-coordinate fixtures, not deposited experimental structures.
The exporter preserves scientific descriptors and coordinate bytes, removes
machine provenance/absolute paths, and updates the portable manifest hash.
Component outputs are included in new server analysis archives; public example
fixtures can be regenerated with the package. Attribution accompanies fixtures.
