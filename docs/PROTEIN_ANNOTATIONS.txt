Protein Annotation Explorer
Route: /tools/protein-annotations

No API keys, paid services, new dependencies, or environment variables are required.
Public provider requests use the Next.js GET endpoint /api/protein-annotations.
Allowed requests are kind=reference|model and a canonical UniProt accession.
Uploaded files never go through this endpoint. No arbitrary upstream URL is accepted.

Inputs and mapping
PDB, CIF/mmCIF, single protein FASTA, or pasted amino acid sequence.
5 MB per file, 30,000 protein atoms, 16 chains, 2,000 observed residues per chain.
First coordinate model, no generated assemblies, no waters or ligands.
Blank and A (or 1 in CIF) alternate conformers are retained; others are omitted.
Only residues with CA coordinates appear. Hydrogen atoms are excluded.
Original author chain, residue number, and insertion code remain in the sequence strip and export.
A private normalized PDB with unique viewer numbering avoids insertion code collisions in 3Dmol.
MSE/SEP/TPO/PTR normalize to M/S/T/Y for sequence alignment.

Reference mapping uses exact substring matching first, then bounded semiglobal dynamic programming.
Scores: +3 exact known match, -2 mismatch, -3 linear gap, free reference terminal gaps.
At most 4 million alignment cells, 90% identity and query coverage required.
Repeated exact fragments and equally scoring alignment paths are withheld.
This is local sequence alignment, not SIFTS or a validated orthology assignment.
The scoring model is not a calibrated homology test; check reference/chain/feature mapping.
Isoform IDs, de novo protein identification, homology searches, and multi-FASTA are not supported.
Sequence-only users provide the canonical reference accession themselves.
AlphaFold loading requires exact full-length sequence identity, matching model sequence and coordinates.

Switching proteins
Load Annotations keeps the loaded structure/sequence, selection, and saved region notes.
The setup panel separately labels the currently viewed protein and the active annotation reference.
Open As New Protein loads the entered accession as a fresh reference sequence, clearing old selections
and notes only after a successful lookup. The AlphaFold button can then open its matching model.
A withheld mapping also offers Open Reference Protein using the already retrieved reference.
Editing the accession alone does not change either the loaded protein or active annotation reference.

Sources
UniProt: https://rest.uniprot.org/uniprotkb/ACCESSION.json
Feature endpoints and location uncertainty preserved. Disulfide bonds/crosslinks map endpoints only.
Feature evidence codes and PubMed/PDB references are preserved, not inferred from reviewed status.
UniProt source entry version and retrieval date are included in export.
InterPro: https://www.ebi.ac.uk/interpro/api/entry/interpro/protein/uniprot/ACCESSION/?page_size=100
Discontinuous fragments preserved separately. Computational signatures labeled as such.
First 100 entries only; truncated results labeled Partial, outages labeled Unavailable.
AlphaFold: https://alphafold.ebi.ac.uk/api/prediction/ACCESSION
Only a validated AlphaFold files URL is fetched. No prediction compute is offered.
No M-CSA, allostery inference, pocket finding, or experimental validation is implemented.
No fake annotation or count is substituted on an upstream failure.

Selections and export
Sequence mouse drag, click, Shift range, Ctrl/Command toggle, keyboard Tab/Enter.
3D click selects; Shift/Ctrl/Command adds/removes. A chain change clears the old selection.
Hovering over the 3D structure shows an in-view amino acid preview with original chain/number,
mapped UniProt position, and up to two annotations with sources. Local features precede broad domains.
There is no intentional hover delay. The hovered residue is pink in both Cartoon and Sticks views.
Leaving the residue restores its annotation or selection color without changing the selection.
The preview uses all annotation types, independently of the side panel filter. Click for full details.
Mapping failures, unmapped residues, and chains other than the mapped chain never show transferred features.
Substitutions and uncertain boundaries are labeled. Escape, leaving the viewer, or rotating dismisses it.
Neighborhoods use CA-to-CA distances in the current chain; they are not atomic contacts.
Notes and up to 30 saved regions remain in memory until the tab closes.
Export JSON includes the selected chain residues, mapping, reference/evidence, selected residues,
and saved regions across chains. It is a review document, not a restorable workspace or structure file.
